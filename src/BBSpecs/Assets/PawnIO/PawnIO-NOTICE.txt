PawnIO — third-party component bundled with BBSpecs
====================================================

BBSpecs includes the official PawnIO installer (PawnIO_setup.exe, version 2.2.0)
so that processor temperature works without asking you to hunt down a separate
download. It is never installed silently: BBSpecs asks first, and declining
leaves your machine untouched.

WHAT IT IS
----------
PawnIO is a scriptable kernel driver that lets programs read hardware registers
safely. Reading a processor's temperature requires executing a privileged CPU
instruction (RDMSR), which no ordinary program is allowed to do — that is why
Task Manager doesn't show CPU temperature either. Every tool that does show it
installs a driver of this kind.

PawnIO replaces the older WinRing0 driver, which granted unrestricted read and
write access to physical memory and was consequently added to Microsoft's
Vulnerable Driver Blocklist. PawnIO runs small sandboxed bytecode modules
instead, and is not blocklisted.

VERIFYING THE BUNDLED BINARY
----------------------------
The installer shipped inside BBSpecs is byte-for-byte the official release:

    File     PawnIO_setup.exe
    Version  2.2.0
    Source   https://github.com/namazso/PawnIO.Setup/releases/download/2.2.0/PawnIO_setup.exe
    SHA-256  1F519A22E47187F70A1379A48CA604981C4FCF694F4E65B734AAA74A9FBA3032

That hash is the one published in Microsoft's winget package repository for
namazso.PawnIO 2.2.0. The file is Authenticode-signed by:

    E=admin@namazso.eu, CN=namazso.eu, O=namazso, L=Debrecen, C=HU

You can confirm both yourself:

    Get-FileHash PawnIO_setup.exe -Algorithm SHA256
    Get-AuthenticodeSignature PawnIO_setup.exe

REMOVING IT
-----------
PawnIO installs as a normal Windows program and can be uninstalled at any time
from Settings, Apps, Installed apps. BBSpecs keeps working without it; only
processor and motherboard temperatures go away.
